## 7. 本机限制与踩过的坑（别重复试）

- **CPU 2 核、无可用 GPU**。Blender 5.2.2（`D:\blender\blender.exe`）只有 **Cycles CPU** 能用；EEVEE Next 和 Workbench 直接崩（EXCEPTION_ACCESS_VIOLATION，只有 OpenGL 1.1 软件实现）。
- **1080p Cycles 不可行**：1080p/8 采样 ≈ 39 秒/帧。实测 **720p/8 采样 ≈ 16.8 秒/帧**，所以 3D 一律 1280×720 渲、再 lanczos 上采样到 1080p。5 秒镜头（24fps=120 帧）约 34 分钟。
- **Remotion 自带的 ffmpeg 是精简版**：没有 `fps`、`setpts`、`tile`、`freezedetect`、`volumedetect`，也没有 null encoder。
  - 改视频速度用输入参数 `-itsscale 1.242857 -r 30`（v3 的 8.7 秒 3D 就是这么来的），不要用 `setpts`。
  - 做九宫格用 PIL 逐帧 `-ss` 抽图拼。
  - 静止检测用 OpenCV（`v3\check_static.py`），音量检测导出 WAV 后用 numpy 算 RMS（`v3\qa_v3.py` 的 `audio_gap`）。
  - 抽单图记得加 `-update 1`，否则会报 image2 pattern 警告。
- **路径**：项目在中文路径下；Git Bash 里用 `/c/Users/...`，Python 里用 `C:\Users\...`。GNU tar 的 `-C C:/...` 会失败，先 `cd` 再用相对路径。`/tmp` 对 Python 不可见，临时文件写到 `out\` 下。
- **Node**：用工程里的 `node_modules/.bin\tsc`，不要在错误的 cwd 下 `npx tsc`（会去网上拉一个假的 `tsc@2.0.4`）。
- **node_modules**：v2 的是**指向 v1 的目录联接**，在 v2 里 `npm install` 等于改 v1；v3 的是**完整独立副本（约 1.0 GB）**。三个工程都不要装包。
- **渲染参数**：`--concurrency=1`；输出先写 `_tmp_` 再改名，失败不覆盖旧成片。
- 没有 `bc`，算术用 `awk`。

1. **序章 28.5–32.7 秒的 GAME OVER 全黑是用户点名要保留的 v1 原效果。** 静止检测会报 29.5–31.0 和 31.0–32.0 两段（合计约 2.5 秒）。这**故意**违反“静止不超过 0.5 秒”的旧规则。

3. 3D 两镜整体偏暗（夜景 + 低采样压时间）；v3 在 Ch09 的 3D 上叠了 `brightness(1.18)`，原素材没改。
4. 尾声 3D 是 v2 的 7 秒素材拉伸到 8.7 秒，没有重渲；GAME OVER 切换落在约 3.0 秒（“999”那句在 3.81 秒）。
