# 链接与依赖说明

## 1. 本仓库内没有链接

发布包是用 `cp -a` 逐个复制出来的，没有软链接、没有 junction、没有 submodule。原工程里的两个目录联接**没有**跟着进来：

| 原路径 | 指向 | 本仓库怎么处理 |
|---|---|---|
| `remotion-studio-mg/node_modules` | RPG Maker 工程的 node_modules（559 MB） | 不收录，`npm ci` 重建 |
| `remotion-studio-mg/public/fonts` | RPG Maker 工程的 `public/fonts`（空目录） | 不收录，见第 3 节字体说明 |

## 2. 脚本里的绝对路径（换机器必须改）

`code/remotion-studio-mg/tools/build_film.sh` 顶部写死了四个变量：

```bash
ROOT="/c/Users/admin/Desktop/ai生成科普视频/癫痫科普/纯MG动画方案/remotion-studio-mg"
FFMPEG="$ROOT/node_modules/@remotion/compositor-win32-x64-msvc/ffmpeg.exe"
PY="C:/tools/Python312/python.exe"
DELIVER="/c/Users/admin/Desktop/ai生成科普视频/癫痫科普/输出文件夹"
```

- `ROOT`：本仓库里应指向 `code/remotion-studio-mg`
- `FFMPEG`：`npm ci` 之后按实际平台改（Windows 是 `compositor-win32-x64-msvc`，macOS/Linux 换成对应包名）
- `PY`：任意装了 numpy 的 Python 3.12
- `DELIVER`：要提前 `mkdir -p`，否则 `cp` 会失败

`tools/render_all.mjs`、`render_stills.mjs`、`render_test_stills.mjs` 用的是 `process.cwd()`，只要在工程根目录执行就正常，不用改。

## 3. 字体（最容易踩的坑）

工程**不含字体文件**，`public/fonts/fonts.css` 在原工程里就不存在（原本是空目录的联接）。`MGFrame.tsx` 加载失败会自动回退：

- `"Noto Sans SC"` → **Microsoft YaHei**
- `"Noto Serif SC"` → 系统衬线（Windows 通常 **SimSun**）

也就是说交付成片用的是系统字体，设计稿里的 Noto 并没有真正生效。

要 1:1 复现（或让字形更好看），二选一：

1. 装字体：Windows 安装 Noto Sans SC / Noto Serif SC，重新渲染即可（浏览器会直接命中系统字体）；
2. 走 webfont：用 RPG Maker 那套 `prepare_fonts.py` 从 `@fontsource` 包生成 `public/fonts/fonts.css` + woff2 目录（脚本在另一个主题里，思路一样）。

## 4. 其它依赖

| 依赖 | 说明 |
|---|---|
| Node 24 + `npm ci` | Remotion 4.0.537 / React 19 / TS 5.7，锁在 `package-lock.json` |
| ffmpeg | 用 Remotion 自带的精简版即可；系统 ffmpeg 只在手动抽帧时用 |
| Python 3.12 | `tools/audio_master.py`（numpy）、`tools/make_srt.py`（标准库） |
| edge-tts | 只在重新配音时需要；音色固定 `zh-CN-YunyangNeural` |
| 内存 | 原机 2 GB 可用内存跑 concurrency 4 没问题；机器更弱就传 `RENDER_CONCURRENCY=2` |

## 5. 哪些东西"看起来缺、其实不缺"

- `public/fonts/` 不存在 —— 原本就是空联接，见第 3 节。
- `public/audio/sfx/` 不存在 —— 这一版**没有任何音效**，章节组件不传 `sfx`。
- `out/` 不存在 —— 渲染输出目录，第一次渲染前 `mkdir -p out/render`。
- 没有配乐文件 —— 原片就没有配乐，只有旁白。
