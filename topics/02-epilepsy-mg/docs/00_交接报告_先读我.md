## 6. 纪律与坑（本主题专属）

1. **junction 绝对不能用 `rm -rf` 删**——那会删穿到 RPG Maker 的真实目录。删除链接用 `fs.unlinkSync` 或 `rmdir`（空壳）。
2. 工程搬家、或 RPG Maker 文件夹改名后，链接会断：运行 `node 工作区域文件夹\_备份\relink_shared.js` 重建；脚本只处理链接，遇到真实目录会拒绝。
3. 快照 `snapshot.sh` 已自动排除 `node_modules`、`.venv`、`out`、`public\fonts`、`public\audio\sfx`，所以 tar 里只有源码/主题素材/文档。
4. **Webpack 缓存必须关**：Remotion 默认把缓存写到 `node_modules\.cache`，实测一次静帧就生成 200 MB；因为 `node_modules` 是共享 junction，这些文件会直接写进 RPG Maker 工程。本工程已在 `remotion.config.ts` 设 `Config.setCachingEnabled(false)`，重渲验证不再生成缓存；代价是每次渲染多花约 10 秒重新打包。别为了提速改回 `true`。
5. `交接文档\` 是文案/资料的唯一真相：下游只读；本主题的文案由本机 AI 代写，`02_文案`、`01_资料库`、`03_制作` 已纳入快照。
6. 旧版本一律保留；新版本新建 `v2\remotion-studio-v2`，不要覆盖 v1。
7. **不要在癫痫工程里跑 `npm install` / `npm ci`**：`node_modules` 是 junction，npm 可能把链接替换成真实目录，白占 559 MB。确需新依赖时先问老板，优先装进共享的 RPG 工程。
8. 本主题是医学内容：宁可少讲，也不能讲错；所有“复原示意/AI 生成”图必须标注，不能冒充实拍或医学影像。
9. 药物段落只讲左乙拉西坦的通用名和原则；**不能写成“影响最小”或“孕妇都能吃”**，必须保留“相对安全、医生指导”的限定。依据见资料库 #23 和 2.6 节。

### 音频母带（重要）

Remotion 自带的 ffmpeg 是精简版，**没有 `volumedetect` / `loudnorm` 滤镜**，所以母带在 `tools/audio_master.py`（numpy）里做：10 ms 包络 → 软压缩（阈值 0.04 / 比 6）→ 按旁白电平补增益 → 0.95 天花板限幅。

- 拼接后原始：整体 RMS 0.031（-30 dBFS）、真峰值 -4.0 dBFS，**偏轻**。
- 母带后：整体 RMS 0.056、真峰值 0.95（-0.45 dBFS）、旁白窗口 RMS p50 0.050 / p95 0.109、无削顶。
- 参数可用 `MASTER_TARGET` / `MASTER_THRESHOLD` / `MASTER_RATIO` 覆盖。
- 混流：`-c:v copy` + 新 AAC，**画面零重编码**，所以母带不用重渲。
