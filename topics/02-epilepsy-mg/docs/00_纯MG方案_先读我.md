## 视觉方向（已定）

- **底色**：暖白纸面 `#FBF6EA` + 细点阵；场景内容是圆角大色块面板，不是黑底。
- **色板**：墨蓝、珊瑚红、芥末黄、青绿、钴蓝、淡紫、粉；高饱和但不刺眼。
- **字体**：中文大标题 Noto Serif SC 900（编辑感），正文与标签 Noto Sans SC 400/700。
- **插画**：纯矢量、扁平、粗线；人物是简化头像/身形，不用照片、不用写实医学影像。
- **字幕**：亮底深字胶囊，不再用黑底白字。
- **动效**：弹性入场、擦除、数字滚动、线条绘制、慢速漂浮；禁止 3 Hz 以上闪烁。
- **叙事**：一章一个主色，一个核心信息图；每章至少一个“大画面”和一个“可读卡片”。

**不要** `npm install`：`node_modules` 是 junction，安装会把共享目录写穿。

### 渲染与交付命令

```bash
cd 癫痫科普/纯MG动画方案/remotion-studio-mg
./node_modules/.bin/tsc --noEmit
node tools/render_all.mjs            # 10 章 -> out/render/ChXX.mp4

# 拼接 + 音频母带 + 交付 + SRT（需 10 章齐全）
bash tools/build_film.sh
```

- 渲染输出：`out/render/Ch00.mp4 … Ch09.mp4`
- 成片：`癫痫科普/输出文件夹/20261023_癫痫科普_纯MG动画版.mp4`
- 字幕：`癫痫科普/输出文件夹/癫痫科普_纯MG动画版_字幕.srt`
- 拼接时音频必须重编码（`-c:a aac`），不要 `-c copy`，否则接缝处 Non-monotonic DTS。
- 音频母带沿用 v1 的参数：`MASTER_THRESHOLD=0.04 MASTER_RATIO=6`，峰值 0.95。
- 本片没有配乐，只有云扬旁白和极少量留白；若后续要加音乐，必须重新做母带。
