## 6. 这台机器上踩过的坑（新增，上游文档里没有）

| 坑 | 结论 |
|---|---|
| `ffmpeg` / `ffprobe` 不在 PATH | 用工程自带的：`node_modules\@remotion\compositor-win32-x64-msvc\ffmpeg.exe` |
| 这个 ffmpeg 是裁剪版 | **没有 `volumedetect` 滤镜**，也没有 null 编码器。测音量要 `-vn -ac 1 -ar 16000 -f wav` 导出后用 Python 算 RMS |
| Git-Bash 的 `/tmp` | Python 看不见 `/tmp`，临时文件写到 `out\` 里再删 |
| GNU `tar` 的 `-C` | 传 `C:/...` 这种 Windows 绝对路径会失败，先 `cd` 再用相对路径 |
| ffmpeg concat 清单 | 路径写反斜杠会出问题，统一换成 `/`（脚本已处理） |
| 渲染中途崩溃 | `render_all.sh` 先写 `_tmp_<id>.mp4`，成功才 rename，所以半截文件不会被当成成品 |
| 拼接用 `-c copy` | 每个 AAC 段的 priming 会和上一段尾巴重叠，ffmpeg 报一串 `Non-monotonic DTS`。**默认改成 `-c:v copy -c:a aac`**：视频还是逐位拷贝不损画质，音频重建成一条连续轨，警告消失 |
| 这个 ffmpeg 没有 `fps` / `tile` 滤镜 | 做目检拼图不能用 `-vf fps=...,tile=...`。改用 `scripts\contact_sheet.py`：逐帧 `-ss` 抽图 + PIL 拼版 |
| `bc` 在 Git-Bash 里没有 | 脚本里的算术一律走 `awk` |

## 9. 三处与上游文档不同的地方（要报告给老板 AI）

1. **第 03 章不是录屏。** 上游文档第二段要求"放门 → 新建事件 → 条件分支 → 开关 → 试玩"的真实 RPG Maker 操作录像。本机没有 RPG Maker 运行时，也没有任何录屏素材（`public\` 下没有一张图、一段视频，全部画面都是代码画的）。现在的做法是用 `src\film\editor.tsx` 手绘复刻编辑器界面来演这段逻辑——地图树、图块面板、事件表、条件分支弹窗、开关 ON/OFF 试玩，流程是完整的，气质也对（本来就是 2D 界面），但**它不是真实软件截图**。如果老板要求真录屏，需要另外提供素材，这一章重做。
2. **字幕是烧进画面的**，不是外挂轨。`ChapterBase.tsx` 的 `Subtitles` 按 `film.json` 的 500 条 cue 逐帧显示，所以交付的 MP4 自带字幕，不需要再压。若要 B 站稿件用的 SRT，可以从 `工作区域文件夹\voice\film\narration.json` 直接生成，但当前没做。
3. **画面里的"复原"都打了标。** 手绘的包装、网页、场景右上角有"场景复原示意 / 包装复原 / 根据公开资料复原"之类的小字标，不是水印，是刻意的事实边界声明——这些不是当年的真实截图。别裁掉。
