### 2.1 省空间复用（junction，2026-10-23 起）

新主题**不要整包复制模板工程**：只有 KB 级、且要按主题改写的源码才复制；重资产一律用 Windows 目录联接（junction）共享。`癫痫科普\工作区域文件夹\v1\remotion-studio-v1` 是按这个方式搭好的现成实例：

| 新主题里的路径 | 联接目标（RPG Maker） | 大小 |
|---|---|---|
| `node_modules` | `RPG Maker科普\工作区域文件夹\remotion-studio\node_modules` | 559 MB |
| `public\fonts` | `RPG Maker科普\工作区域文件夹\remotion-studio\public\fonts` | 13 MB |
| `public\audio\sfx` | `RPG Maker科普\工作区域文件夹\remotion-studio\public\audio\sfx` | 12 MB |
| `voice\.venv` | `RPG Maker科普\工作区域文件夹\voice\.venv` | 21 MB |

- 复制（需按主题改）：`src\film\` 通用组件、工程配置、`scripts\`、`voice\*.py`。
- 断链/搬家后：`node 癫痫科普\工作区域文件夹\_备份\relink_shared.js`（只重建链接，遇到真实目录会拒绝）。
- **junction 不能用 `rm -rf` 删**，那会删穿到真实目录；删除用 `fs.unlinkSync` 或 `rmdir` 空壳。
- 快照脚本要排除这些链接（`--exclude='*/public/fonts'`、`*/public/audio/sfx`、`node_modules`、`.venv`、`out`），tar 里只留源码/主题素材。
- **Remotion 的 webpack 缓存默认写在 `node_modules\.cache`**（实测一次静帧 200 MB），junction 模式下会直接写进共享工程。新主题的 `remotion.config.ts` 必须加 `Config.setCachingEnabled(false)`；代价是每次渲染多约 10 秒重新打包。癫痫工程已这么设。

## 5. 坑 → 解法（照抄能省一天）

**画面/节奏**

- 画面像按了暂停 → 每个镜头套一层极慢的双频正弦推拉/漂移（0.5 秒移动 4–6 像素）；漂移太轻会被检测抓出来，太重会显得晃，这个量是调过的。
- 压缩时长会砍掉镜头编排 → 用“场景时钟”：给每个节拍一个 scale，把组件内部的 local frame 乘以 scale，动作整体加速而不是丢帧。
- 中文标签换行重叠 → 像素字体的短标签要 `whiteSpace:'nowrap'` 并调小字号。

**拼接 / 编码**

- 用 `-c copy` 拼接 → 每个接缝都报 Non-monotonic DTS。**必须** `-c:v copy -c:a aac -b:a 192k -ar 48000 -ac 2`。
- 抽单张图片报 image2 pattern 警告 → 加 `-update 1`。

**精简版 ffmpeg 缺东西**

- 没有 `setpts` / `fps` 滤镜 → 改速度用输入参数 `-itsscale 1.242857 -r 30`。
- 没有 `tile` → 九宫格/关键帧对照表用 PIL 自己拼。
- 没有 `freezedetect` → 静止检测用 OpenCV：每 0.5 秒采样、缩到 320×180、平均灰度差 < 0.35 记一次，连续合并成窗口。
- 没有 `volumedetect` → 导出 WAV 用 numpy 算每 1 秒 RMS，找最长静音段。

**Blender**

- EEVEE / Workbench 崩 → Cycles CPU + 720p + 降噪 + AgX，再上采样。
- GLB 模型导入躺倒 → 相机/物体约束里 `con.up_axis = "UP_Y"`（**不是** Z；Z 配 TRACK_NEGATIVE_Z 是退化组合）。
- 屏幕贴图换图变全黑 → 别用两个面或 `hide_render`；一个面 + 两个 Emission + Mix Shader，用可打关键帧的 Value 节点的**输出**去驱动 Fac。
- Blender 5.x 的 `Action` 不再暴露 `action.fcurves` → 别写那段调插值的代码。
- 城市/背景楼群“不见了” → 先检查路径拼接有没有多写字段名，再确认贴图 `colormap.png` 一起解压了。

**环境 / 工具链**

- `npx tsc` 有时会去网上装一个假的 `tsc@2.0.4` → 一律用 `node_modules\.bin\tsc`，且 cwd 必须在工程根。
- Git Bash 的 `/tmp` 对 Windows 版 Python 不可见 → 临时文件写到工程 `out\` 下。
- GNU tar 的 `-C C:/...` 会失败 → 先 `cd` 再用相对路径；带空格/中文路径要引号。
- 没有 `bc` → 算术用 `awk`。
- Steam 抓图：`https://store.steampowered.com/api/appdetails?appids=<id>&filters=basic,screenshot`；**梦日记要用 appid 650700**（114700 在国内返回 `success:false`）；Fandom / itch / archive.org 在这台机器上取不到。
- **node_modules 目录联接**：搬动工程目录后，junction 仍指向旧绝对路径 → 用 PowerShell `[System.IO.Directory]::Delete($link)` 删链接、`New-Item -ItemType Junction` 重建。**绝对不要用 `rm -rf` 删 junction**，那会删穿到真实目录。
- 目录改名报 Permission denied：多半是有程序（资源管理器窗口、播放器、索引器）打开了那个目录或里面的文件。文件本身没锁时，**逐层搬子项**就能绕过去，最后空壳目录再删。

**另一个必须记住的限制**：默认落在工作区根的 `vibe_images\`，要**手动挪进主题文件夹**，别散在外面（本次已挪好并删了空目录）。

### 11.4 选题时的取舍

- **需要“真实画面”**（游戏实机、老杂志、史料）→ 仍然走真实来源（Steam 官方 API 抓图等），AI 生图不能冒充实拍，来源要记进 `image_credits`。
- **需要“复原示意 / 概念氛围图”** → AI 生图很合适，标注“AI 生成 / 复原示意”。
- **需要精确可控的构图与逐帧一致** → 还是 Blender 脚本化渲染（第 5 节），AI 生图给不了逐帧确定性。
- **需要人物剪影、立绘、Q 版角色这类“没有真人素材就只能画”的东西** → 直接用自带生图，见 11.6。

### 11.6 什么时候直接叫自带生图（剪影 / 立绘 / Q 版 / 氛围图）

做科普片经常卡在“这个画面既没有史料照片，又不值得为它建 3D”。这类**一律先用 `ImageGen` 出图**，别手写 SVG 硬凑、也别开 Blender。

**该用它的（已实测）**

| 素材类型 | 为什么用它 |
|---|---|
| **人物剪影 / 逆光人物**（少年玩家、开发者、匿名叙述者） | 一次出图就能用，见下面实测数据 |
| **人物立绘、Q 版/二头身角色** | 我们没有美术，画不出来；生图能保持同一角色描述复现 |
| **时代氛围底图**（80 年代书房、秋叶原夜景、机房、杂志内页质感） | 当背景层压暗+加颗粒，比纯色块有信息量 |
| **概念示意**（“一个世界被造出来”这类抽象画面）、片头片尾插画、纹理/纸张底 | 同上 |

**不该用它的**：真实游戏实机画面、真实人物长相、史料照片、任何要“有据可查”的图像——那些必须走真实来源并记进 `image_credits`，AI 图不能冒充实拍。

**实测数据（两张样张在 `工具测试\生图通道\`）**

- `qoder-imagegen_低多边形卧室CRT.png`：1792×1024、2.08 MB，低多边形卧室 + CRT 里的蓝鲸鱼，可直接当“复原示意”镜头。
- `qoder-imagegen_人物剪影.png`：1024×1024、**0.27 MB**，逆光少年握手柄剪影。实测 **97.4% 的像素亮度 <8、四角平均 RGB≈(0,0,0)** → **背景是纯黑，直接叠在任何暗色画面上就行，不用抠图**（要更融合就 `mixBlendMode:'screen'`）。黑底也让 PNG 压积极小。

**出图规范（照抄）**

1. 尺寸只能用枚举值：`1024x1024 / 1536x1024 / 1024x1536 / 768x1024 / 1024x768 / 1024x1280 / 1280x1024 / 1024x1792 / 1792x1024 / 2560x1080`。**没有 1280x720**，要 16:9 用 `1792x1024`。
2. 要能直接叠画面，就在提示词里写死 **“背景必须是纯黑/纯白，不要任何环境元素”**（黑底用于 screen 叠加，白底用于乘算或当蒙版）。
3. 角色一致性：每次把同一段外观描述整段复制进提示词（发型、脸型、服装、配色），别每次改写。
4. 命名与落盘：`qoder-imagegen_<用途>.png`，从工作区根的 `vibe_images\` **立刻挪进** `<主题>\工作区域文件夹\<工程>\public\images\ai\`，并删掉空的 `vibe_images\`。
5. 在 `image_credits` 里标 **“AI 生成（Qoder ImageGen / qwen-image-2.0-pro）”**，与真实截图严格分开。
6. 水印固定在**右下角**且位于纯色区：优先用构图避开、或被字幕条/暗角遮住；不能裁掉整块画面的时候再考虑换 `provider:"bailian"` 自带 key（那时不走 Qoder 积分）。

**可直接抄的提示词模板**

```
剪影：纯黑背景，一个人物全身剪影：<姿势与道具>，轮廓清晰锐利，内部无细节，
      边缘带极淡的<暖/冷>色描边光，居中构图，海报素材风格，不要文字。

立绘：全身角色立绘，<年龄/身份/服装/配色/发型>，纯黑背景，正面微侧站姿，
      双手自然下垂，赛璐璐上色，边缘光清晰，无投影，不要文字。

Q 版：二头身 Q 版角色，<同上外观要点>，表情夸张友好，纯色平涂，
      粗黑描边，纯黑背景，居中，不要文字。

氛围底图：<年代/地点>室内，低多边形 3D 渲染风格，<主体物件>，
      低调照明 + 单一暖光源，窗外冷蓝夜色，电影感，不要文字。
```

**在 Remotion 里怎么用**：`staticFile('images/ai/xxx.png')` + `<Img>`；纯黑底的图放在暗色场景上直接可见，或套 `mixBlendMode:'screen'` 与任何深色底融合；再交给现有的 `Drift`/Ken Burns 做缓慢推拉，就不会变成静止画面（第 5 节）。

**成本**：一次生图就是这次 Agent 请求里的一步，官方没有单列生图计价（见 11.3）；真正贵的是本地渲染时间，所以**多生几张图挑一张，比多渲一遍章节便宜得多**。

### 12.5 必踩的坑（已解决，照抄）

- **Windows 版 Chromium 拒绝加载完整中文 CFF 字体**：`OTS parsing error: CFF : Failed validating CharStrings INDEX`，页面会静默回退系统字体。**必须**先跑 `python <skill>/scripts/fonts.py film/` 子集化（215 MB → 4.3 MB），改了屏上文字要重跑。

- 字幕烧录用 `ass=xxx.ass:fontsdir=fonts`；`ass` 滤镜**只吃 .ass，喂 .srt 会报 `Could not create a libass track`**，srt 要用 `subtitles=` 滤镜。已实测中文正常。
