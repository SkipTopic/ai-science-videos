## 0.0 已知取舍（别当成 bug）

- **序章 28.5–32.7 秒的 GAME OVER 黑场是故意的。** 这段是 v1 原效果：0.3 秒淡入、约 3.1 秒全黑、再 0.8 秒淡出。用户明确选择“完全照 v1”，`check_static.py` 会报 29.5–31.0 和 31.0–32.0 两段 frozen（合计约 2.5 秒；淡入淡出期间画面在变，所以不计入）。不要再“修”成短黑场或硬切。
- 序章标题卡 94–95 秒有 1 秒缓漂（min diff 0.23，画面仍在动）；Ch02/03/05/07/08 也有 1 秒级缓漂窗口，与 v2 完全相同。这是全局 Drift 经过正弦拐点造成的，不是新引入的冻帧。
- 3D 素材没有重渲，是把 v2 的 7 秒 30fps 片段用 `-itsscale` 拉伸到 8.7 秒；GAME OVER 切换落在约 3.0 秒，正好在“999”那句（3.81 秒）之前。
- 3D 画面在 Remotion 里加了 `filter: brightness(1.18)`，只是为了看清卧室家具；原素材和 v2 工程没改。
- 全片总时长仍是 **15:52.21**（952.21 秒），音频没有重配。
- `v3/remotion-studio-v3/node_modules` 是完整复制（约 1.0 GB），不是目录联接。v3 可以独立跑；不要在里面 `npm install`，也不要删除它去指向 v1。

```bash

"$FF" -y -itsscale 1.242857 -i public/video/crt_pullback.mp4 \
  -r 30 -t 8.7 -an -c:v libx264 -crf 18 -pix_fmt yuv420p \
  public/video/crt_pullback_v3.mp4
```

3D 原始工程和素材仍在 v2，没有复制：
