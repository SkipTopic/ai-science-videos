## 4. 视频生成能力

- 方式：AI 直接编写 React/Remotion 代码，逐帧确定性渲染，不依赖视频生成模型
- 已验证：TypeScript 类型检查、150 帧 1080p 渲染、Remotion Studio 启动、MP4 输出
- 可制作：片头、文字动效、图表/数据动画、2D/2.5D 图形动画、字幕、转场、SVG/Canvas/WebGL、配音与音效（Remotion Audio）
- 3D 动画：Blender 5.2.2 LTS（Cycles CPU）。已验证「PNG 序列 → ffmpeg 合成 MP4」；该 5.2 构建不支持直接导出 FFmpeg/MP4。
- Blender MCP：官方 MCP 扩展 1.0.3 已安装并启用（localhost:9876），服务端在 `C:\blender_mcp\mcp`；已接入 Qoder（条目 `BlenderMCP`，26 个工具），实测可读取当前场景。需保持 Blender 5.2 打开；新增 MCP 后若当前会话未显示工具，下一次对话或重启 Qoder 生效。
- MMD：Blender 5.2 已启用 MMD Tools，可导入 MMD 模型与动作，适合千本樱类 MV。
- 旁白：edge-tts 7.3.1 + 云扬（`zh-CN-YunyangNeural`，专业男声）；逐句合成并导出 SRT，默认语速 0%，可按片调整。
- 可扩展：AE 2024 与 Maya 2024 已安装，可作为后续素材制作或 3D 渲染能力
- 建议规格：1080p / 30fps，单条 10–90 秒
- 性能提示：4 线程、7.7 GB 内存且无 GPU，4K 或长视频会明显变慢；并发建议 2–3

## 6. 交付规则与注意事项

- 所有成片必须放到 `输出文件夹`；工程内 `out/` 只放截图等中间产物。
- 成片交付前检查：可正常播放、时长/分辨率/帧率正确、文件名符合约定。
- Blender 固定使用 5.2（`D:\blender`）；4.5 不使用、不修改（无 MCP 扩展）。
- Blender MCP 依赖 Blender 5.2 GUI 进程；关闭 Blender 后 MCP 工具不可用。
- `C:\tools\nodejs` 原本缺 `npm`/`npx` 启动脚本，已补齐官方脚本，这是唯一的系统级改动。
- 项目记忆中的交付规则：`C:\Users\admin\.qoder-cn\projects\C--Users-admin-Desktop-ai------\memory\project-video-pipeline.md`
