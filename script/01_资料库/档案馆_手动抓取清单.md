# 档案馆手动抓取清单

> 脚本抓 archive.org 会被 429 拦死，所以这一份留给你手动存。
> 全部是 WAYBACK MACHINE（互联网档案馆）的页面。

---

## 怎么存

1. 浏览器打开下面的链接
2. **等页面完全加载**——顶部会出现一条灰黑色的档案工具栏，出现才算加载完
3. `Ctrl + S`
4. 保存类型选 **「网页，仅 HTML」** 或 **「单个文件（.mhtml）」**
5. 存到：`D:\作业\我写的小说\rpgmaker解说\01_资料库\_raw_html\Z_archive\`
6. 文件名用我给的（比如 `Z01_ascii_2000.html`）

**如果页面打不开 / 显示 429：**
- 等 5 分钟再试，不要连续刷
- 或者把年份换掉（2000 → 1999 / 2001），档案会自动跳到最近的快照
